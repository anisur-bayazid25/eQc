# eQc 1.8.1

This release connects notes to writing through the new **Memo-Book** tab.

- **Memo-Book:** find notes across documents, codes, quotations, cases, annotations, framework and co-occurrence matrices, and Code Map. Search, filter, select and edit notes, then return to their sources.
- **Word and Excel:** export a single memo, a selected set or all notes. Excel separates memo types into worksheets; Word uses category headings.
- **Manuscript support:** code summaries, linked memos, analysis notes and starred evidence feed the manuscript skeleton, available directly in Memo-Book.
- **Simpler Help:** concise offline instructions and a dedicated Memo-Book section. Research tools now contains Cases, Groups, Review and History.
- **About:** right-click the email or GitHub link to copy its address.
- **Performance:** indexed memo lookups, 50-card pages and less repeated work during manuscript export.
- **Demo kit:** a downloadable fictional climate study with four English interviews, three simulated coders, a questionnaire/codebook, memos and a video guide. Use it to practise ICR and consensus.

Existing project backups remain supported. Keep a JSON backup before major changes or consensus adjudication.
