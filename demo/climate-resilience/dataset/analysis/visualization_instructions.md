# Fictional visualization examples

Open Visualization → Saved drafts. The Histomap draft uses Amina, seven themes and four researcher-defined event phases. The Dendrogram draft groups four interviews using all 24 direct-code presence features and Amina only. Use ⚙ to review instructions, change filters and regenerate.

Period tags refer to the time described in a passage, not interview/import dates. The dataset has uneven sentence-level coding: some sentences have one code, some overlap, and many are uncoded. Exact duplicate coder ranges count once in unique-passage mode; coder disagreements remain available for ICR. The counts CSV links every tag back to evidence. No trend or cluster is an empirical claim about these countries.
